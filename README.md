# 🏛️ Fundação Agostinho Neto - Website Institucional

> Site institucional da Fundação Agostinho Neto, desenvolvido com HTML, CSS e JavaScript.

---

## 📌 Descrição

Este projeto consiste na criação de um website institucional para a **Fundação Agostinho Neto**, com o objetivo de divulgar informações sobre a fundação, sua história, missão, atividades e eventos.

O site foi desenvolvido utilizando tecnologias web fundamentais, com foco em simplicidade, acessibilidade e boa experiência do utilizador.

---

## 🚀 Tecnologias Utilizadas

- 🌐 HTML5  
- 🎨 CSS3  
- ⚡ JavaScript (Vanilla JS)

---

## ✨ Funcionalidades

- 🏛️ Página institucional sobre a fundação
- 📖 Secção sobre a história de Agostinho Neto
- 📰 Publicação de notícias e eventos
- 📸 Galeria de imagens
- 📱 Design responsivo para dispositivos móveis
- 📬 Página de contacto
